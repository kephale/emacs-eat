# Eat: Emulate A Terminal

Eat is a terminal emulator for Emacs, written entirely in Emacs Lisp.

> **This is an unofficial mirror. Eat is developed at
> [codeberg.org/akib/emacs-eat](https://codeberg.org/akib/emacs-eat).**
> Please report issues and send changes there.

## Install

Eat is on NonGNU ELPA:

```
M-x package-install RET eat RET
```

Installing from Git? Use the Codeberg URL, or `master` if you need this mirror:

```sh
git clone https://codeberg.org/akib/emacs-eat
git clone -b master https://github.com/kephale/emacs-eat
```

See [Eat's README](https://github.com/kephale/emacs-eat/blob/master/README.org#installation)
for Quelpa, Straight.el and older Emacs versions.
